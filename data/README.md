# Data and analysis for system ablation and analysis of the Abelio

This repository contains the inference data, evaluation prompts, and analysis scripts for the Abelio system ablation and analysis. 

```
data/       inputs: objectives, hypotheses (text + embedding), literature, judge scores
prompts/    evaluation prompts: soundness judge, writing-stage summary, frontier generation
analysis/   the analysis code (figure.py is the entry point)
results/    outputs of analysis/figure.py: fig2.png, fig2.svg
```

The scripts are handled via uv.

## Labels

| label in data | meaning |
|---|---|
| `baseline` | the Abelio Ideation Core — called "Ideation Core" in a–c and "full pipeline" in d–g |
| `embody_bypass` | Ideation Core with the Formulation stage bypassed |
| `elements_bypass` | Ideation Core with the Element Selection stage bypassed |
| `debate_bypass` | Ideation Core with the Refinement stage bypassed |
| `gemini_31_pro_preview`, `gpt_52_high`, `claude_opus_46`, `grok_41_fast_reasoning` | the frontier models Gemini 3.1 Pro Preview, GPT-5.2 (high reasoning), Claude Opus 4.6, Grok 4.1 Fast Reasoning |

A hypothesis is identified by (`label`, `goal`, `task_name`); the judge-score files use
`config` and `task` for the same two fields.
`embodiment_index` is the formulation index, and `embody`, `elements` and `debate` in the arm labels are the data's names for formulation, element selection and refinement.

## Data

All 50 research objectives were given to every system.

| file | rows | contents |
|---|---|---|
| `goals.jsonl` | 50 | each objective and its constraints |
| `hypotheses.jsonl` | 1,344 | hypotheses as generated by the four pipeline arms (293 / 388 / 287 / 376) — used in d–g |
| `hypotheses_predebate.jsonl` | 752 | the ideation output before Refinement, for the full pipeline and the Element Selection bypass (376 each) — used in e (before Refinement) |
| `hypotheses_summarized.jsonl` | 293 | writing-stage summaries of the Ideation Core's hypotheses — used in a–c |
| `single_model.jsonl` | 1,317 | frontier-model hypotheses (Gemini 263, GPT-5.2 418, Opus 4.6 407, Grok 229) — used in a–c |
| `literature.jsonl` | 500 | the ten papers retrieved for each objective (`idx` 0–9); `text` holds title, year, source, DOI and abstract, and `embedding` is its embedding |
| `soundness_scores_summarized.jsonl` | 4,830 | judge scores for the summaries and frontier hypotheses, three judges each — a–c |
| `soundness_scores_hypos.jsonl` | 4,032 | judge scores for hypotheses as generated, all four pipeline arms, three judges each — d–g |

`text` is the exact text that was embedded and judged, and `embedding` is its 4096-dimensional,
L2-normalized embedding. Each judge-score row holds one judge's
integer scores (1–10) for grounding, sharpness and feasibility, and the judge's rationale
for its grounding score.

Notes on what the files contain:

- **Literature.** For each objective, the objective and its constraints were used as the
  query to a literature search over OpenAlex; the ten top-ranked papers were kept.
- **Refinement outcomes.** The Refinement stage can return a hypothesis as unsalvageable
  or drop it after its internal review. Those hypotheses are absent from
  `hypotheses.jsonl` and from the score files. `hypotheses_predebate.jsonl` holds every
  ideation output, including those later removed by Refinement.
- **Frontier non-responses.** Entries under 50 words are non-responses and were excluded;
  there was one (Claude Opus 4.6, `goal_11`, a single narration line). Claude Opus 4.6
  returned no hypotheses for `goal_21` and `goal_27`.
- **Writing-stage summaries.** Only the Ideation Core's hypotheses were summarized; the
  frontier models were prompted to write abstracts directly.

## Prompts

The agent configurations as used, unmodified.

| file | used for |
|---|---|
| `prompts/idea_judge.toml` | scoring every hypothesis on grounding, sharpness and feasibility (1–10 each) |
| `prompts/writing_matcher.toml` | summarizing Ideation Core hypotheses into 130–200-word abstracts for the comparison in a–c (Claude Opus 4.8) |
| `prompts/baseline_ideation.toml` | generating hypotheses with each frontier model, once per objective; `{{core_goal}}` is the objective and `{{constraints}}` its constraints |

**Judge.** Each hypothesis was scored by three judges drawn from a pool of seven — Claude
Opus 4.8, GPT-5.5 (high reasoning), Gemini 3.5 Flash, Grok 4, DeepSeek V4 Pro, Qwen3.5
397B and GLM 5.2 — by a seeded shuffle, with no exclusion of a model's own developer;
the `model` field in `idea_judge.toml` is a placeholder overridden per call. DeepSeek, Qwen
and GLM were accessed through OpenRouter, the others through their providers' APIs. If a
judge call failed, the next model in that hypothesis's order was used. 

**Frontier models.** Each model ran with its built-in search tool (the `if.model_type`
blocks in `baseline_ideation.toml`), with no retry.

## Analysis

| file | contents |
|---|---|
| `analysis/figure.py` | builds every panel and writes the figure |
| `analysis/measures.py` | literature distance, soundness and diversity, per-objective aggregation, the paired Wilcoxon test and Holm adjustment |
| `analysis/stage_effects.py` | panel g |
| `analysis/boxstats.py` | box-plot drawing and colours shared by the panels |

Statistics: the objective is the unit of analysis. Arms are compared with two-sided
paired Wilcoxon signed-rank tests on per-objective values over objectives both arms
cover. P values are Holm-adjusted across the four frontier models for each measure (c),
across the three bypassed stages (d, e after Refinement, f), and across the six
non-pre-specified cells of g; e before Refinement is unadjusted. a and b are descriptive.
